# CLAUDE.md — this vault

This folder is a personal knowledge vault of markdown notes.

## Where things live
- Daily notes: `daily/YYYY/MM/YYYY-MM-DD.md` — full date in the filename, always.
- Terminal logs: `terminal-logs/daily-logs/YYYY/MM/` (machine-written, never hand-edit).
- Daily summaries: `terminal-logs/daily-summaries/YYYY/MM/` (written by scripts/summarize.py).
- Projects: `projects/<name>/`.

## Rules
- `private/` is confidential. Never read it, quote it, or send it anywhere.
- Prefer editing an existing note over overwriting it. This vault is not in git.
- Draft any email or message to a file under `drafts/`. Never send anything.
- When asked where a dated note is, answer with the exact path from the pattern above; do not search.

## Memory
`memory/MEMORY.md` is an index of decisions and preferences, one line each, pointing at one-fact files in `memory/`. Read it at the start of every session. When the user makes a decision worth keeping, write a new one-fact file and add a line to the index.
